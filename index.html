How to add Toastify to your project

      
Five steps from an empty page to working notifications. Every example is ready to copy.

    


    

      
      

        

          
Add the script

          
Choose how you want to load the library. Every option gives you the same Toastify object. The CSS is built in, so there is no stylesheet to add.

          

            
            
            
            
          


          

            

              
index.html


<!-- Put toastify.js in your project folder, then load it before your own script -->
<script src="toastify.js"></script>
<script src="app.js"></script>

            

          


          

            

              
index.html


<!-- jsDelivr serves files straight from a public GitHub repo.
     Replace USERNAME and REPO with your own. -->
<script src="https://cdn.jsdelivr.net/gh/esnaidinkanakan/toastify@v1.0.0/toastify.js"></script>

            

          


          

            

              
src/main.js


// Copy toastify.js into src/lib/, then import it
import Toastify from './lib/toastify.js';

Toastify.success('Loaded with a bundler');

            

            
The file is a UMD module, so import, require() and a plain script tag all work.

          


          

            

              
src/SaveButton.jsx


import Toastify from './lib/toastify.js';

export default function SaveButton() {
  async function handleSave() {
    await Toastify.promise(saveDraft(), {
      loading: 'Saving draft…',
      success: 'Draft saved',
      error: 'Could not save. Try again.'
    });
  }
  return <button onClick={handleSave}>Save</button>;
}

            

            
Toastify adds its own container to document.body, so you do not need a provider or a component in your tree.

          

        

      


      
      

        

          
Show your first toast

          
Call a shortcut with a message. Each shortcut sets the type, which controls the icon and color.

          

            
app.js


Toastify.success('Profile updated');
Toastify.error('Payment failed');
Toastify.warning('Your session ends in 5 minutes');
Toastify.info('A new version is available');

// Add a title by passing an object
Toastify.success({ title: 'Order placed', message: 'We sent a receipt to your email.' });

          

          

            
          

        

      


      
      

        

          
Choose where it appears

          
Pass a position to any toast. Each position keeps its own stack, so toasts in different corners never overlap. Click a position to see it.

          

          

            
app.js


Toastify.info('Shown at the bottom left', { position: 'bottom-left' });

Toastify.show({
  type: 'success',
  title: 'Copied',
  message: 'Link copied to clipboard',
  position: 'top-center'
});

          

        

      


      
      

        

          
Set defaults once for your whole site

          
Call configure() when the page loads. Every later toast uses these settings unless you override them on that toast.

          

            
app.js


Toastify.configure({
  position: 'bottom-right',
  duration: 5000,       // milliseconds; 0 keeps it open until closed
  theme: 'auto',        // light | dark | colored | auto (follows the visitor's OS)
  animation: 'slide',   // slide | fade | zoom | bounce
  maxToasts: 3,         // per position; the oldest closes first
  width: 380,
  offset: 20
});

Toastify.success('Uses the defaults above');
Toastify.error('Overrides one setting', { position: 'top-center' });

          

          
If your site has its own dark mode toggle, pass the current theme when you show a toast: Toastify.info('Hi', { theme: isDark ? 'dark' : 'light' }). This page does that with the “Match page” option.

        

      


      
      

        

          
Handle real actions: loading, results and undo

          
Wrap any promise, such as a fetch call, with Toastify.promise(). It shows a spinner, then switches to success or error when the request finishes. Use actions to add buttons.

          

            
app.js


// 1. Loading → success / error
const form = document.querySelector('#contact-form');

form.addEventListener('submit', (e) => {
  e.preventDefault();
  Toastify.promise(
    fetch('/api/contact', { method: 'POST', body: new FormData(form) })
      .then((res) => { if (!res.ok) throw new Error(); return res; }),
    {
      loading: 'Sending your message…',
      success: { title: 'Message sent', message: 'We will reply within a day.' },
      error:   { title: 'Not sent', message: 'Check your connection and try again.' }
    }
  );
});

// 2. An action button
Toastify.show({
  type: 'info',
  message: 'Item moved to trash',
  duration: 6000,
  actions: [{ label: 'Undo', primary: true, onClick: () => restoreItem() }]
});

// 3. Update a toast you already showed
const t = Toastify.loading('Uploading 0%');
t.update({ message: 'Uploading 60%' });
t.update({ type: 'success', message: 'Upload complete', duration: 3000 });
